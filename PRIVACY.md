# Privacy Policy

Effective date: 2026-09-09

AI Review Skills is a skills-only Plugin. It does not operate a developer-controlled server, require an account, use cookies, or transmit user content to the Plugin developer.

The Plugin instructions may ask the active ChatGPT or Codex runtime to process files supplied by the user, retrieve sources through capabilities available in that runtime, or create local/generated artifacts. Those operations are performed by the host product and are subject to the user's OpenAI account, workspace, retention, and tool settings. The Plugin developer does not receive or retain prompts, uploaded files, generated reports, citations, or extracted images.

Bundled Python and shell helpers operate only in the runtime where the user invokes them. They do not contain telemetry, analytics, authentication, or developer-operated network endpoints. Web research, when requested, uses source-access capabilities supplied by the host rather than a service operated by this Plugin.

Users should not provide secrets or personal data that are unnecessary for their requested analysis. Generated artifacts may contain text, quotations, citations, or images derived from user-provided files and selected sources; users control where those artifacts are saved or shared.

Questions and deletion requests concerning OpenAI-hosted conversation or file data should be handled through the applicable OpenAI account or workspace controls. Plugin-specific privacy questions may be submitted through the repository support channel listed in `SUPPORT.md`.
