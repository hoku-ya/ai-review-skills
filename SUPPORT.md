# Support

Use the public GitHub repository for support:

- Documentation: https://github.com/hoku-ya/ai-review-skills
- Issues: https://github.com/hoku-ya/ai-review-skills/issues

Before opening an issue, include the Plugin version, product (`ChatGPT Chat`, `Work`, or `Codex`), execution location (`Local`, `Cloud`, or `Unknown`), invoked Skill, expected behavior, actual behavior, and whether `SKILL.md` loaded. Do not include confidential documents, API keys, access tokens, or personal data.

Security-sensitive reports should not contain exploit details or secrets in a public issue. Request a private contact channel from the repository owner instead.
